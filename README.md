# سامانه گزارش‌دهی حفاظت فیزیکی

فرم وب حرفه‌ای برای ثبت گزارش‌های گشت شبانه، گزارش بیماری و موارد نیازمند پیگیری.

## ویژگی‌ها

- 🎨 ظاهر مدرن با فونت وزیرمتن
- 📍 انتخاب آبشاری محل → پست (فیلتر پویا)
- 👥 انتخاب چندنفره پرسنل با چیپ
- 🔍 جستجوی زنده در فهرست ۱۸۳ نفره پرسنل
- 📷 پیش‌نمایش عکس قبل از ثبت
- 👁️ پنهان‌سازی خودکار توضیحات/عکس در وضعیت «عادی»
- 💾 ذخیره‌سازی محلی (localStorage) بدون نیاز به سرور
- 📥 خروجی CSV با پشتیبانی کامل از فارسی (UTF-8 BOM)
- 📱 طراحی واکنش‌گرا (موبایل و دسکتاپ)

## اجرا

فایل `index.html` را در مرورگر باز کنید، یا:

```bash
python -m http.server 8000
```

سپس به `http://localhost:8000` بروید.
